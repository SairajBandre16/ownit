# Sentence openers
> When several sentences in a row start the same way ("The …", "This …", "Moreover, …"), the text sounds mechanical.

## Why it matters
The first words of a sentence set up what the reader expects. Repeating the same opener hides the logic between sentences: is this a cause, a contrast or just the next item?

## How to fix it
- Start with the condition or reason: "Because the fuse blew, the pump stopped."
- Start with time or place when it matters: "After ten minutes, …", "In the second test, …".
- Start with the subject that is new, not the one you just mentioned.
- Use a linking word only when the link isn't obvious.

## Example
**Before:** The sensor reads the soil moisture. The controller compares it with the set point. The pump starts when the soil is dry.

**After:** The sensor reads the soil moisture, and the controller compares it with the set point. When the soil is dry, the pump starts.

## Try it
Read only the first two words of each sentence in one paragraph. If they repeat, rewrite one opener.
