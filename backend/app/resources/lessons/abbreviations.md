# Abbreviations
> Define an abbreviation the first time you use it: "programmable logic controller (PLC)". Then use only "PLC".

## The rules
- **Define at first use**, full name first, abbreviation in brackets.
- **Define once.** Defining again later confuses the reader. (It's fine to define it once in the Abstract and once in the main text.)
- **Only abbreviate what you repeat.** If an abbreviation appears once, write the full name instead.
- **Plurals take a plain "s":** "PLCs", not "PLC's".
- **Very common ones** (USB, LED, DC) usually need no definition; check your department's guide.

## Why examiners care
In a viva, "what does MOSFET stand for?" is a common opening question. Defining it in your report means you've looked it up.

## Example
**Before:** The PLC reads the LDR every second. A light dependent resistor (LDR) changes resistance with light.

**After:** A programmable logic controller (PLC) reads a light dependent resistor (LDR) every second. The LDR's resistance falls as light increases.

## Try it
List every abbreviation in your report. Next to each, write the full name without looking. Those you can't are your viva homework.
