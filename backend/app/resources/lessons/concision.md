# Concision
> Say it in fewer words when fewer words say the same thing.

## Why it matters
Wordy phrases ("in order to", "due to the fact that", "at this point in time") add length without adding meaning. Examiners read many reports; a tight one feels confident and is easier to mark.

## How to fix it
- "in order to" → "to"
- "due to the fact that" → "because"
- "has the ability to" → "can"
- "a large number of" → "many" (or, better, the number)
- "it is important to note that" → delete it and state the point
- "make a decision" → "decide"; "conduct an analysis of" → "analyse"

## Example
**Before:** In order to reduce the losses, it is important to note that the controller has the ability to make a decision at this point in time.

**After:** To reduce the losses, the controller can decide immediately.

## Try it
Take any sentence over 20 words and cut five words without losing meaning.
